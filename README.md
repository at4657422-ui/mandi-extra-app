# मंडी एक्स्ट्रा (Mandi Extra)

भारत के लिए खरीद-बिक्री का प्लेटफ़ॉर्म: ख़रीदार और विक्रेता सीधे बात करते हैं, बिचौलिया नहीं।
Buy-sell marketplace for India where buyers and sellers talk directly, no middlemen.

शुरुआत: मध्य प्रदेश। बाद में: पूरा भारत।

## ज़रूरी नियम

1. कोई भी गुप्त चाबी (API key, पासवर्ड) कभी इस रिपॉज़िटरी में नहीं डालनी।
2. कमीशन अधिकतम 2% रहेगा, और यह `app_settings` में एडमिन से बदलता है।
3. पेमेंट की पुष्टि सिर्फ़ सर्वर या एडमिन से होती है।
4. असली यूज़र और असली पैसे आने से पहले सिक्योरिटी जाँच और वकील की समीक्षा करवाइए।
